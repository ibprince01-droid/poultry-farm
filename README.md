# Poultry-Farm
## Business Process Modeling
Egg collection, stock control and sale in the Poultry Farm Management System. A farm worker records eggs collected per flock and the system validates the entry and updates stock. A buyer places an order and the system checks stock.procedure saves the sale and payment, reduces stock, and a trigger writes the audit log. The manager then reviews stock and sales reports.
